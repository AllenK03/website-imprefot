# Imprefot.com - E-Commerce & Multi-Service Platform

Production web application built for **Imprefot 09**, combining an online store for stationery, printing products, and electronics with a registration-free service request system integrated with WhatsApp sales operations.

### 🛠️ Tech Stack
* **Framework:** Laravel 12.0
* **Frontend & Interactivity:** Livewire, Tailwind CSS, Vite
* **Admin Panel:** Filament PHP
* **Database:** MySQL
* **Integration:** WhatsApp Web API, Google Maps GPS
